> MTD aims to shift the advantage of time from the attacker to the defender [ghosh2009nitrd, zhuang2012].

Context before: [U0015 cites ghosh2009nitrd] A static network keeps such reconnaissance valid and lets an attacker plan at its leisure [ghosh2009nitrd]. [U0016 cites cho2020] Moving target defence (MTD) changes a network's addresses, layout, software and credentials on a schedule, so that stolen credentials and reconnaissance go out of date even if the attacker is never detected [cho2020].

Context after: [U0018 cites alshamrani2019] MTD has been proposed as a defence against APTs [alshamrani2019], yet it is rarely tested against one. [U0019 cites cho2020,jalowski2026,hong2018] Most tests run in simulation, against attacker models far simpler than an APT [cho2020, jalowski2026], and how MTD is measured to perform depends on how the attacker is implemented [hong2018].
