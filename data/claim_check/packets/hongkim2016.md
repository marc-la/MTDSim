> How to move is one of three operations, the shuffle--diversity--redundancy (SDR) taxonomy [hongkim2016].

Context before: [U0052 cites cho2020] An MTD is designed by answering three questions: ``what to move'', ``how to move'' and ``when to move'' [cho2020]. [U0053] What to move is a configurable attribute, such as an IP address, the network topology, an operating system or a piece of software.

Context after: [U0055] Shuffling rearranges or randomises existing components, such as addresses or links, so that the attacker's reconnaissance no longer holds. [U0056] Diversity replaces a component with a different implementation of the same function, so that an exploit against one no longer applies.
