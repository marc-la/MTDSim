# The MTDSim lineage

MTDSim was built and extended by four studies supervised by Jin B. Hong at UWA.
The simulator in `src/mtdnetwork/` is theirs; Chapter 2 describes what each added.

| Study | Report |
|---|---|
| Brown, Lee and Hong 2023, *Evaluating Moving Target Defenses against Realistic Attack Scenarios*, IEEE/ACM EnCyCriS 2023 | [doi:10.1109/EnCyCriS59249.2023.00005](https://doi.org/10.1109/EnCyCriS59249.2023.00005) (IEEE copyright, not redistributed) |
| Zhang 2023, *Evaluating Multiple Moving Target Defence in the Time Domain*, UWA | [zhang2023.pdf](zhang2023.pdf) |
| Ho 2024, *Using Artificial Intelligence to Automate the Deployment of MTD Operation*, UWA | [ho2024.pdf](ho2024.pdf) |
| Tay 2024, *Using Artificial Intelligence to Automate the Deployment of Moving Target Defence Operations*, UWA | [tay2024.pdf](tay2024.pdf) |

The three UWA reports are byte-identical to the final reports the upstream
repository published (`docs/thesis/` at https://github.com/Bsubs/MTDSim).
