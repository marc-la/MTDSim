## Relevant artefacts

### What the dataset is — 23 Caldera campaigns, 12 APTs, sequences + telemetry

**Source locator:** Abstract; §III-B/C (testbed); §IV-A (emulation); Table II

**Paraphrase:** a Caldera testbed (attack box + Windows/Linux target VMs with
Filebeat/Winlogbeat + ELK monitoring box) running **23 campaigns across 12
APT groups** — APT41 (G0096), APT39 (G0087), APT32 (G0050), APT10 (G0045),
APT28 (G0007), APT5 (G1023), Aquatic Panda (G0143; the md parse prints
"Asiatic" — reconciled via the group ID), APT3 (G0022), WindShift (G0112),
Dragonfly (G0035), APT29 (G0016), APT35 (G0059) — with 11–20 techniques per
campaign, **83 techniques** covered, and **up to 290 abilities across 14 MITRE
tactics**. Adversary profiles were hand-built from CTI ("we were not able to
find playbooks that describe the attack sequences for APTs, we referred to
multiple CTI sources and built attack paths based on them" — §IV-A). Shared
per campaign: adversary profile, abilities, low-level ELK telemetry, and the
technique sequence.

**Disposition for this thesis:** verified [fetched] — the emulation-corpus
counterpart of our Attack Flow corpus: independently CTI-derived *sequences*,
which corroborates structure-from-CTI as a method while carrying no timing.

### The timing verdict — timestamps exist, adversary tempo does not

**Source locator:** §IV-A final para ("Each ability displays the timestamp at
which it was executed, the status, the command executed…"); §IV-B (ELK
standard features incl. timestamp); confirmed against the repo by the
precedent survey (curated `Sequence.json` = `{Node, Tactic, Technique}`, no
timestamps; raw `logs.7z` = ELK events with `@timestamp`)

**Paraphrase:** Caldera operations execute the profile's abilities
**sequentially at machine speed**; every ability execution and log event is
timestamped, but those timestamps measure *testbed execution latency*, not
adversary dwell — no pacing, jitter beyond Caldera defaults, or
literature-informed tempo is claimed anywhere in the paper. The curated
sequence artefact drops time entirely. Consequence: per-technique
*inter-ability deltas are derivable* from the raw logs (same status as DARPA
OpTC/TC — a heavy, new sourcing category, flagged not assumed in scope), but
nothing in this dataset can justify a per-tactic dwell.

**Maps to:** [`../notes/2026-07-04_tactic_duration_precedent_survey.md`](../notes/2026-07-04_tactic_duration_precedent_survey.md)
§"Corpora: sequence yes, timing no" · state-durations handoff hard constraint
(timing never comes from a corpus).

**Disposition for this thesis:** verified [fetched] — gap-documenting; do not
re-mine for dwell values.

### Dwell colour — the LightBasin anecdote

**Source locator:** §I (Introduction)

**Paraphrase:** motivating examples of extended dwell: **LightBasin remained
undetected for five years (2016 → discovery in 2021**, per CrowdStrike);
APT41 active since 2016 across many sectors. Whole-campaign, second-hand —
consistent with M-Trends-scale dwell tails, no per-tactic content. Ref [4]
also points at Mandiant's "2023 Time-to-Exploit Trends" (vulnerability
disclosure→exploitation lag — a different clock from ours; pointer only).

**Disposition for this thesis:** verified [fetched] (as reported there;
anecdote, not a statistic).

### An emulated APT41 kill chain (structure corroboration)

**Source locator:** §IV-A + Fig. 4 (APT41 Windows profile, 20 techniques)

**Paraphrase:** the narrated path — initial access on a server → system/user/
file discovery → web-protocol C2 + BITS tool download → password cracking →
privileged-account creation + Windows-service modification (persistence) →
network/share exploration → browser-credential theft → collect + archive for
exfiltration → clear event logs/command history + disguise tasks (stealth) →
scheduled task. Ordering texture only; matches the tactic chaining our L2
surfaces encode; no times.

**Disposition for this thesis:** verified [fetched] — background
corroboration for §2-type claims, already covered by Step B sources; no §4
value.
