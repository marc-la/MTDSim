\chapter{Introduction}
\label{ch:intro}

% Landmark-to-landmark compression straight to the gap (writing guide:
% the examiner has largely judged the work by the end of this chapter).
% Order when drafted: motivation hop -> the grey box below -> compact
% methodology (V5: corpus -> profiles -> executable movement attacker ->
% evaluation against the inherited baseline) -> one highlight result
% (the anchor inversion, once the V1 hand-validation pass clears it) ->
% contributions -> roadmap. Written last, many refinement passes.

% The single-RQ decision (architecture (a)) is intact: the sub-questions
% are methodological decomposition, not sub-problems.
\begin{tcolorbox}[colback=black!5!white, colframe=black!40!white,
                  title={Research question}, coltitle=white, sharp corners]
How does moving target defence (MTD) perform against advanced
persistent threat (APT) attackers?

\medskip
\noindent The question is answered in three parts. \emph{First,
capture}: how is APT attacker behaviour captured, from published
campaign intelligence to behavioural attack profiles? \emph{Second,
model}: how is the captured behaviour made executable, as an attacker
that traverses the captured structure inside the simulator?
\emph{Third, evaluate}: how does MTD performance against the APT attack
model differ from its performance against the inherited scripted
attacker, on the standard metric suite and on the APT-specific measures
that suite cannot express?
\end{tcolorbox}
