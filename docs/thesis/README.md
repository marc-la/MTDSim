# Dissertation source

*Evaluating moving target defence against advanced persistent threat attackers
modelled on documented intrusion campaigns*, Marc Labouchardiere (23857377),
supervised by Jin B. Hong, UWA. Built on the UWA `cshonours` class (title page
changes tagged `%mtd`).

| Path | What it is |
|---|---|
| `dissertation.tex` | the dissertation |
| `references.bib` | bibliography |
| `figures/`, `tables/` | the floats; generated by `tools/build_floats.py` (README, "Reproducing the dissertation"), never edited by hand. A file is named for where it first sat in the text (`fig_<chapter>-<section><order>_<name>`), which can differ from its printed number |
| `proposal.pdf`, `proposal.tex` | the semester-one proposal, included as Appendix A |
| `seminar/` | the seminar deck source; the built slides are `docs/seminar.pdf` |

Build from the repository root with `make thesis` (pdflatex, bibtex, pdflatex ×2);
the PDF lands here and a copy of the submitted build is `docs/dissertation.pdf`.
