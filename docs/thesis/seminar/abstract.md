**Title:** Evaluating moving target defence against advanced persistent threat attackers modelled on documented intrusion campaigns

**Presenter:** Marc Labouchardiere

**Supervisor:** Dr Jin B. Hong

**Abstract**

Some attackers break into a network and stay for years. One state-sponsored group held footholds in American critical infrastructure for at least five years, using what it had learned about networks that never changed. Moving target defence (MTD) aims to stop such attackers by continually changing a network, such as its addresses or software, so that what an attacker has learned goes out of date. MTD is usually tested against simple simulated attackers that repeat the same fixed steps, so how it performs against such attackers is largely unmeasured.

This project builds an attacker modelled on real intrusions. It is drawn from 38 published, hand-drawn maps of the steps real attackers took, grouped by what each attacker was after, such as stealing data or disrupting systems. At each step, the attacker chooses its next move from what those intrusions did. It runs inside an existing MTD simulator beside the simulator's original scripted attacker, on the same networks and against the same defences.

The talk shows that, in the simulator, which defence works best depends on the attacker. One defence cuts the number of computers the scripted attacker takes over by 92%, but the new attacker's by only 36%.
