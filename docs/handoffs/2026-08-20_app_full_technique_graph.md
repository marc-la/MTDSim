# The full technique-level attack graph — appendix figure

**Goal:** a full-page appendix render of the generalised technique-level
aggregate attack graph at a declared edge-weight threshold, so the structure is
visible line-by-line **(ruled 2026-08-20)**. The chapter keeps `fig:l1-graph`;
this is its uncompressed counterpart, cited from §4.2.1.

## State of play

- `tools/l1_attack_graph_figure.py` already draws the technique-level
  aggregate small as `fig:l1-graph` panel (b), from `data/gap/gap_v0.5.json` —
  **extend this tool** (a full-page mode), never a parallel script.
- **The rider CONFIRM (one word from Marc):** `fig:l1-graph` itself stays in
  §4.2.1 — today's "no diagram at this level" is read as *no new* in-prose
  diagram. Removal instead would strand three prose refs, the drawn 88 % claim
  (panel b) and the drawn pre-intrusion sparsity (panel c).

## Spec

- Full technique-resolution aggregate, edges at/above a **declared weight
  threshold** — a `--threshold` flag with the chosen value stated in the
  caption, never hard-coded (mechanism-not-exception applies to figure
  tooling).
- Same grey ramp / dark-recurring-core, faint-tail encoding as panel (b), so
  the pair read as one system at two zooms.
- Caption: threshold declared, ATT&CK pin stated (§b5), corpus span stated
  (38 flows, 2017–2024), encodings decoded.

## Considerations

1. **Legibility drives layout**: a full technique graph at `\textwidth` will
   fail the ~8pt rule; expect landscape (`pdflscape`) or a rotated full-page
   float. Check printed size, not screen.
2. **The threshold is a presentation choice, and the caption owns that** — the
   underlying L1 GAP is lossless; this figure shows a view. One sentence in
   the caption keeps an examiner from reading the threshold as data loss.
3. **The pin question rides**: the v19.1 pin still owes its
   `sec:experimental-setup` home (standing loose thread) — this caption states
   the pin but does not discharge that debt.
4. Cite it from §4.2.1 with a parenthetical on an existing sentence — the
   placement (and whether any prose changes at all) is Marc's.
